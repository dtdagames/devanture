# Inscription au stage de poterie pour enfants
Ce composant permet à un parent d'inscrire ses enfants à un stage de poterie pour enfants.
Le titre affiché en haut est fourni par la page qui utilise le composant, il n'y a pas de texte d'introduction.
Le formulaire demande le nom du parent, son adresse e-mail, le nombre d'enfants, sous forme de nombre entier, et un message facultatif.
Le bouton d'envoi affiche « Inscrire mes enfants ».
Le stage compte six places en tout, sans groupes, et chaque inscription en retire autant qu'il y a d'enfants.
Lorsqu'il ne reste pas assez de places, l'inscription est mise en liste d'attente et le visiteur voit le message « Le stage est complet, vous êtes sur liste d'attente. »
Une même adresse e-mail ne peut s'inscrire qu'une seule fois.
Lorsque l'inscription est enregistrée, le visiteur voit le message « C'est noté, à bientôt à l'atelier. »
Les inscriptions sont rangées dans le registre « stages ».
L'atelier n'est pas prévenu par e-mail de chaque inscription.
Le composant affiche le nombre de places qui restent.
