# Appel à bénévoles de la bourse aux vélos
Ce composant recueille les inscriptions des personnes qui veulent donner un coup de main comme bénévoles à la bourse aux vélos.
Le titre qui précède le formulaire n'est pas dans le composant : la page qui l'utilise le fournit, et le composant n'ajoute aucune introduction.
Le formulaire demande le nom, l'adresse e-mail, le téléphone et un message libre, ce dernier étant facultatif.
Le bouton d'envoi affiche « Je participe ».
Il n'y a pas de limite de places.
Une même adresse e-mail ne peut s'inscrire qu'une seule fois : une seconde tentative affiche le message « Vous êtes déjà inscrit comme bénévole. »
Après un envoi réussi, le visiteur voit le message « Merci, nous vous recontactons vite. »
Les inscriptions sont enregistrées dans le registre « benevoles ».
À chaque nouvelle inscription, l'équipe reçoit un e-mail.
