# faq

Questions fréquentes en accordéon (question, réponse).

Ordre : 60
Mots-clés : questions, faq, comment, est-ce que

## Données
- title : texte, facultatif
- intro : texte, facultatif
- items (liste, au moins 1) :
  - q : texte — question
  - a : texte — réponse (paragraphes séparés par une ligne vide)

## Forme
section, conteneur « faq-inner » :
- en-tête : title, intro
- accordéon de items, question q, réponse a

## Exemple
```
## Questions : Questions fréquentes
- Livrez-vous partout en France ? | Oui, sous 48 h ouvrées.
- Puis-je retourner un produit ? | Vous avez 14 jours pour changer d'avis.
```
