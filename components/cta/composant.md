# cta

Bandeau d'appel à l'action (titre, texte, bouton). À placer en fin de page.

Ordre : 70
Mots-clés : contact, demande, devis

## Données
- title : texte
- text : texte, facultatif
- button : lien
- style : texte, facultatif, un parmi primary, surface — fond coloré (primary) ou discret (surface), défaut primary

## Forme
section, variante style par défaut primary, conteneur « cta-inner » :
- bloc :
  - titre : title
  - texte : text
- bouton : button

## Exemple
```
## Appel : Un projet en tête ?
Devis gratuit sous 48 h.
Demander un devis → /contact
```
