# site.header

En-tête du site, rendu en haut de chaque page : le nom du site, le menu, le panier d'une boutique, la recherche. Un site le remplace en écrivant un composant dont la forme s'ouvre par « en-tête de site ».

Ordre : 900

## Forme
en-tête de site :
- marque du site
- menu du site :
  - panier du site
  - recherche du site
